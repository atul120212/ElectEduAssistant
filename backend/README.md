# Election Process Education Assistant - Backend

## Setup

1. `npm install`
2. Configure `.env` based on `.env.example`
3. `npm run prisma:generate`
4. `npm run prisma:migrate` (Make sure PostgreSQL is running)
5. `npm run dev`

## Technologies
- Node.js + Express
- TypeScript
- Prisma ORM
- PostgreSQL
- Anthropic Claude API
- JWT Authentication
